# Archive

Earlier generations of BLOOM. Nothing here is developed further; the current software
is at the repository root ([`../README.md`](../README.md)). Paths inside these folders
were written before the move and may still say `v1/`, `pony/` or `garden/` without the
`archive/` prefix.

| Path | What it was |
| --- | --- |
| [`v1/`](v1/) | First proof of the Pond and Garden loop: Springboard, Wordstream, Particles, Wi-Fi setup, one recorded turn. |
| [`pony/`](pony/) | Pony P1: LILYGO T7-S3 handheld with a Mac server doing speech to text and a tool-using agent. |
| [`garden/g4q4-setup/`](garden/g4q4-setup/) | Gemma 4 on the Jetson Orin Nano Super: install and run scripts, RAM and speed benchmarks. The current installer reuses its model choice and server flags. |
